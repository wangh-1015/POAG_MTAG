### Codes availability ###
# Codes for "Integrative fine-mapping and single-cell analyses identify novel genes, cell types, and drug candidates for glaucoma"

# This file contains codes and example data for Fig. 2 - 6. 
# Note, Fig. 1 was made by Biorender.

1. To replicate the plot using R, you need to install R and essential R packages first,
All the R packages used in our codes are listed in each R script. After installing R
packages, you have to use "setwd()" to set the parent director of our folder as your  
main director. Then you could run the codes for data loading and ploting.

2. Most example data are provided in "/code_package/data", However, some large
datasets such as single cell RNA/ATAC was not provided.
Note, these data are just an example and may not be complete. For MTAG manhattan 
plot, we only provide significant SNPs (p<5e-8) for replication.
